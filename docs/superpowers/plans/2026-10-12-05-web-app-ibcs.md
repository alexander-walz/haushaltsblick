# Plan 5: Web-App und IBCS-Dashboards – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Haushaltsblick bekommt seine öffentliche Web-App: Start, Explorer, Plan und Wirklichkeit, Titelsteckbrief, Suche, Datenqualität, Methodik, Impressum und Datenschutz. Alle Diagramme und Tabellen folgen IBCS, alle Zahlen stammen aus dem Schema `api`.

**Architecture:**
- **App:** Next.js 16 in `apps/web` rendert Seiten und SVG-Diagramme als Server Components.
- **Datenzugriff:** `lib/daten` ruft die Funktionen im Schema `api` per GET über die Data API auf. Jede Antwort wird mit Zod geprüft und mit dem Tag `datenstand` gecacht.
- **Regelwerk:** `lib/ibcs` ist reine, getestete Logik für Formatierung, Maßstab, Notation, Farbregel und Titel. Die Komponenten in `components/ibcs` setzen sie nur um.
- **Backend:** Es wird additiv um die Wirkungsrichtung nach E21 erweitert. Der Workflow `ingest` frischt nach jeder Veröffentlichung den Cache auf und wärmt ihn vor.

**Tech Stack:**
- Next.js 16.3.6, React 19.3.0, TypeScript 7.0.2, Tailwind CSS 4.3.3, lucide-react 1.48.0, Zod 4.6.5.
- Tests: Vitest 5.0.3 (Unit- und Render-Tests mit `react-dom/server`), Playwright 1.63.0 mit @axe-core/playwright 4.13.0 (Ende-zu-Ende und Barrierefreiheit).
- Backend wie in Plan 4: Supabase, dbt, Vitest-Integrationstests.

**Spec:** `docs/superpowers/specs/2026-10-12-plan-5-web-app-design.md` zusammen mit `docs/superpowers/plans/2026-10-08-00-roadmap.md` (E1, E3, E13, E14, E16, E18 bis E20) und `docs/KONZEPT.md` Abschnitte 10 und 13.

## Global Constraints

- **Aus Plan 1 bis 4:**
  - Migrationen nur additiv, nie `db:reset`, `pipeline_version` bleibt 0.3.0.
  - Funktionen im Schema `api` sind `security definer` mit festem `search_path`, entziehen PUBLIC ausdrücklich das Ausführungsrecht und haben keine Überladungen.
  - Fehler werfen sie mit `errcode 22023`.
- **Die App rechnet keine Zahlen.**
  - Erlaubt sind Formatierung, Maßstab für die Darstellung, Sortieren und Auswählen von Zeilen sowie Betragsbildung für Text („7,0 Mrd. € weniger“).
  - Jede fachliche Zahl kommt aus `get_dataset_status`, `query_metric`, `search_entities`, `get_titel_detail`, `list_kennzahlen` oder `get_glossar`.
- **Eine Version je Seite:** Jede Seite holt zuerst `get_dataset_status` und übergibt allen Aufrufen `p_version = stand.version`.
- **IBCS-Notation:**

  | Szenario | Darstellung | CSS-Klasse |
  | --- | --- | --- |
  | Ist | dunkel gefüllt | `ibcs-ist` |
  | Soll | Kontur | `ibcs-soll` |
  | Entwurf | Kontur, als Entwurf gekennzeichnet | `ibcs-entwurf` |
  | Haushaltsplan (XML) | Kontur gestrichelt | `ibcs-haushaltsplan` |
  | Ist Vorjahr | hellgrau gefüllt | `ibcs-ist-vorjahr` |
  | Soll Vorjahr | hellgraue Kontur | `ibcs-soll-vorjahr` |

  Soll ist auch ohne Ist eine Kontur.
- **Farbregel E21:**
  - Abweichungen Ist gegen Soll werden nur nach der `wirkungsrichtung` aus `query_metric` gefärbt.
  - Vergleiche zum Vorjahr sind immer neutral.
  - Eine Farbe nie ohne Vorzeichen.
  - CSS-Klassen: `ibcs-pos`, `ibcs-neg`, `ibcs-neutral`.
  - Magenta `#EC008C` (`--hb-akzent`) nur für Auswahl, Fokus und Hover, nie als Datenfarbe.
- **Zahlen:**
  - `de-DE` mit `tabular-nums`; Minuszeichen `−` (U+2212).
  - Beträge ab 1 Mrd. in „Mrd. €“ mit einer Nachkommastelle, ab 1 Mio. in „Mio. €“ mit einer Nachkommastelle, ab 1 Tsd. in „Tsd. €“ ohne, darunter „€“ ohne.
  - Prozent mit einer Nachkommastelle und schmalem geschütztem Abstand (` %`).
  - Fehlende Werte als `n. v.`.
- **Texte:** deutsch, kurz, partnerschaftlich. Keine Halbgeviert- oder Geviertstriche in UI-Texten. Bewertungsfreie Kernaussagen (E13).
- **Standardjahre:** Explorer und Start zeigen das laufende Haushaltsjahr. „Plan und Wirklichkeit“ zeigt das letzte Jahr mit Ist. Welche Jahre ein Ist haben, steht in `get_dataset_status.jahre`.
- **Umgebungsvariablen:**
  - Pflicht: `HB_API_URL`, `HB_API_KEY`.
  - Für den Cache: `REVALIDATE_TOKEN`.
  - Für deterministische Tests: `HB_HEUTE`.
  - Für das Impressum: `HB_IMPRESSUM_NAME`, `HB_IMPRESSUM_ANSCHRIFT`, `HB_IMPRESSUM_KONTAKT`.
  - Nichts mit `NEXT_PUBLIC_`.
- **Paketversionen exakt wie im Tech Stack:** keine weiteren Abhängigkeiten, auch kein d3 und kein supabase-js.
- **Barrierefreiheit:** WCAG 2.2 AA. Jedes Diagramm ist zugleich Tabelle oder hat eine Tabellenalternative. Fokus sichtbar, Bedienung per Tastatur.

## Abweichungen von der Spec (Entscheidungen beim Planen)

1. **Spec 7.2, Tempo:** Messungen am 12.10.2026 in der Produktion zeigen einen kalten Datenbank-Cache als Ursache.
   - Die Zinsabfrage lief beim ersten Aufruf ins Zeitlimit, beim zweiten in 288 ms.
   - Ein Teilindex hilft nicht, weil alle Zeilen der Historie aktuell sind.
   - Statt Indexarbeit: Cache in Next.js, ein Wiederholungsversuch bei `57014` und Aufwärmen der Hauptseiten nach jeder Veröffentlichung (Task 4 und 16).
2. **d3 entfällt:** Der Maßstab ist eine lineare Abbildung in zehn Zeilen (`lib/ibcs/skala.ts`).
3. **Explorer mit dritter Sicht „nach Arten“** (Hauptgruppe › Obergruppe › Gruppierung › Titel). Die Suche liefert für Synonyme wie „Steuern“ oder „Kredite“ Gruppierungen, die sonst ins Leere führen würden.
4. **Wirkungsregeln für die Methodik:** `list_kennzahlen` liefert zusätzlich die Wirkungsregeln, damit die Methodikseite sie aus der Datenbank zeigt.
5. **Titelsteckbrief:** Die Wirkungsrichtung kommt aus `query_metric` für den Titel des gewählten Jahres und gilt für die ganze Zeitreihe; die Titelnummer und damit die Obergruppe bleibt über die Lineage gleich.
6. **Ende-zu-Ende-Tests mit aufgezeichneten API-Antworten** statt Pixel-Snapshots. Schriftdarstellung unterscheidet sich je Betriebssystem, Pixelvergleiche wären unzuverlässig. Die Prüfung mit axe bleibt.
7. **Datenzugriff per GET** (`Accept-Profile: api`) statt POST, damit Next.js die Antworten cachen kann. Am 12.10.2026 gegen die Produktion geprüft.
8. **Soll als Kontur auch auf der Startseite:** Der Entwurf zeigte Soll vereinfacht gefüllt; IBCS verlangt die Kontur.
9. **Drosselung der Suche:** über eine Firewall-Regel bei Vercel (Betrieb), nicht im Code.
10. **Mobile Tabellen:** Nebenspalten werden unter 640 px ausgeblendet, nicht aufgeklappt.

Danach `api.list_kennzahlen` vollständig ersetzen:

```sql
create or replace function api.list_kennzahlen(p_version bigint default null)
returns jsonb
language plpgsql
stable
security definer
set search_path = pg_catalog, pg_temp
as $$
declare
  v ops.dataset_version := semantic.version_oder_aktuell(p_version);
  v_sem bigint := semantic.semantik_von(v);
begin
  return jsonb_build_object(
    'version', v.version_id,
    'semantik_version', v_sem,
    'kennzahlen', (
      select coalesce(jsonb_agg(jsonb_build_object(
               'kennzahl_id', k.kennzahl_id, 'name', k.name, 'definition', k.definition, 'formel', k.formel,
               'einheit', k.einheit, 'braucht_jahr', k.braucht_jahr) order by k.reihenfolge), '[]'::jsonb)
      from semantic.kennzahl k where k.semantik_version_id = v_sem),
    'wirkungsrichtung', (
      select coalesce(jsonb_agg(jsonb_build_object(
               'regel_id', w.regel_id, 'konto', w.konto, 'typ', w.typ, 'schluessel', w.schluessel,
               'richtung', w.richtung, 'begruendung', w.begruendung) order by w.regel_id), '[]'::jsonb)
      from semantic.wirkungsrichtung w where w.semantik_version_id = v_sem));
end $$;
```

```ts
/** Heutiges Datum; HB_HEUTE (YYYY-MM-DD) macht Tests und aufgezeichnete Ende-zu-Ende-Läufe deterministisch. */
export function heute(env: Record<string, string | undefined> = process.env): Date {
  const wert = env.HB_HEUTE;
  if (!wert) return new Date();
  if (!/^\d{4}-\d{2}-\d{2}$/.test(wert)) throw new Error(`HB_HEUTE muss YYYY-MM-DD sein, nicht ${wert}`);
  return new Date(`${wert}T12:00:00Z`);
}
```

```ts
  mio: { faktor: 1e6, kurz: 'Mio. €', nachkomma: 1 },
  tsd: { faktor: 1e3, kurz: 'Tsd. €', nachkomma: 0 },
  eur: { faktor: 1, kurz: '€', nachkomma: 0 },
} as const satisfies Record<string, Einheit>;

export const MINUS = '−';
export const NICHT_VERFUEGBAR = 'n. v.';

type Wert = number | null | undefined;

/** Einheit nach dem betragsgrößten Wert; eine Darstellung verwendet genau eine Einheit (IBCS). */
export function einheitFuer(werte: readonly Wert[]): Einheit {
  const max = werte.reduce<number>((m, w) => (w === null || w === undefined || !Number.isFinite(w) ? m : Math.max(m, Math.abs(w))), 0);
  if (max >= 1e9) return EINHEITEN.mrd;
  if (max >= 1e6) return EINHEITEN.mio;
  if (max >= 1e3) return EINHEITEN.tsd;
  return EINHEITEN.eur;
}

function zahl(wert: number, nachkomma: number): string {
  return new Intl.NumberFormat('de-DE', { minimumFractionDigits: nachkomma, maximumFractionDigits: nachkomma }).format(Math.abs(wert));
}

function mitVorzeichen(text: string, gerundet: number, immer: boolean): string {
  if (gerundet < 0) return MINUS + text;
  if (immer && gerundet > 0) return `+${text}`;
  return text;
}

export function betrag(wert: Wert, einheit: Einheit, opt: { vorzeichen?: boolean } = {}): string {
  if (wert === null || wert === undefined || !Number.isFinite(wert)) return NICHT_VERFUEGBAR;
  const gerundet = Number((wert / einheit.faktor).toFixed(einheit.nachkomma));
  return mitVorzeichen(zahl(gerundet, einheit.nachkomma), gerundet, opt.vorzeichen ?? false);
}

export function betragMitEinheit(wert: Wert, opt: { vorzeichen?: boolean } = {}): string {
  if (wert === null || wert === undefined || !Number.isFinite(wert)) return NICHT_VERFUEGBAR;
  const einheit = einheitFuer([wert]);
  return `${betrag(wert, einheit, opt)} ${einheit.kurz}`;
}

export function euro(wert: Wert): string {
  if (wert === null || wert === undefined || !Number.isFinite(wert)) return NICHT_VERFUEGBAR;
  return `${betrag(wert, EINHEITEN.eur)} €`;
}

/** Anteil als Bruch von 1 (0,376 → 37,6 %). */
export function prozent(anteil: Wert, opt: { vorzeichen?: boolean } = {}): string {
  if (anteil === null || anteil === undefined || !Number.isFinite(anteil)) return NICHT_VERFUEGBAR;
  const gerundet = Number((anteil * 100).toFixed(1));
  return `${mitVorzeichen(zahl(gerundet, 1), gerundet, opt.vorzeichen ?? false)} %`;
}

export function ganzzahl(n: number): string {
  return new Intl.NumberFormat('de-DE', { maximumFractionDigits: 0 }).format(n);
}
```

```ts
/** Maßstab über alle Werte einer Darstellung; die Null liegt immer im Bereich (Balken beginnen an der Nulllinie). */
export function masstab(werte: readonly (number | null | undefined)[]): Masstab {
  let min = 0;
  let max = 0;
  for (const w of werte) {
    if (w === null || w === undefined || !Number.isFinite(w)) continue;
    if (w < min) min = w;
    if (w > max) max = w;
  }
  if (min === 0 && max === 0) max = 1;
  return { min, max };
}

/** Gemeinsamer Maßstab mehrerer Darstellungen gleicher Einheit (IBCS: gleiche Skalierung). */
export function vereinige(...m: readonly Masstab[]): Masstab {
  return { min: Math.min(0, ...m.map((x) => x.min)), max: Math.max(0, ...m.map((x) => x.max)) };
}

export function position(wert: number, m: Masstab, breite: number): number {
  return ((wert - m.min) / (m.max - m.min)) * breite;
}

export function balken(wert: number, m: Masstab, breite: number): { x: number; breite: number } {
  const nulllinie = position(0, m, breite);
  const ende = position(wert, m, breite);
  return { x: Math.min(nulllinie, ende), breite: Math.abs(ende - nulllinie) };
}
```

```ts
import type { z } from 'zod';
import { konfiguration, type Konfiguration } from './konfig';

export type RpcWert = string | number | boolean | null | undefined | readonly string[] | { readonly [k: string]: unknown };

export class ApiFehler extends Error {
  constructor(message: string, readonly status: number, readonly code: string | null) {
    super(message);
    this.name = 'ApiFehler';
  }
}

/** Alle API-Antworten tragen diesen Cache-Tag; /api/revalidate verwirft ihn nach jeder Veröffentlichung. */
export const CACHE_TAG = 'datenstand';
const ZEITLIMIT = '57014';

export type RpcOptionen = { abruf?: typeof fetch; konfig?: Konfiguration; warten?: (ms: number) => Promise<void> };

function pgArray(werte: readonly string[]): string {
  return `{${werte.map((w) => `"${w.replace(/\\/g, '\\\\').replace(/"/g, '\\"')}"`).join(',')}}`;
}

/** GET-Aufruf einer Funktion im Schema api; GET macht die Antwort für Next.js cachebar. */
export function rpcUrl(basis: string, funktion: string, args: Readonly<Record<string, RpcWert>>): string {
  const params = new URLSearchParams();
  for (const [name, wert] of Object.entries(args)) {
    if (wert === null || wert === undefined) continue;
    if (Array.isArray(wert)) params.set(name, pgArray(wert as readonly string[]));
    else if (typeof wert === 'object') params.set(name, JSON.stringify(wert));
    else params.set(name, String(wert));
  }
  const query = params.toString();
  return `${basis}/rest/v1/rpc/${funktion}${query ? `?${query}` : ''}`;
}

function feld(daten: unknown, name: string): string | null {
  if (typeof daten !== 'object' || daten === null) return null;
  const wert = (daten as Record<string, unknown>)[name];
  return typeof wert === 'string' ? wert : null;
}

export async function rpc<T>(funktion: string, args: Readonly<Record<string, RpcWert>>, schema: z.ZodType<T>, opt: RpcOptionen = {}): Promise<T> {
  const konfig = opt.konfig ?? konfiguration();
  const abruf = opt.abruf ?? fetch;
  const warten = opt.warten ?? ((ms: number) => new Promise<void>((fertig) => setTimeout(fertig, ms)));
  const url = rpcUrl(konfig.url, funktion, args);
  for (let versuch = 1; ; versuch++) {
    const antwort = await abruf(url, {
      headers: { apikey: konfig.key, 'Accept-Profile': 'api', Accept: 'application/json' },
      cache: 'force-cache',
      next: { revalidate: 86_400, tags: [CACHE_TAG] },
    } as RequestInit);
    const text = await antwort.text();
    let daten: unknown;
    try {
      daten = JSON.parse(text);
    } catch {
      throw new ApiFehler(`Antwort von ${funktion} ist kein JSON (HTTP ${antwort.status})`, antwort.status, null);
    }
    if (!antwort.ok) {
      const code = feld(daten, 'code');
      // Kalter Datenbank-Cache auf Supabase Free: der zweite Versuch ist meist schnell (Messung 12.10.2026).
      if (code === ZEITLIMIT && versuch < 2) {
        await warten(400);
        continue;
      }
      throw new ApiFehler(feld(daten, 'message') ?? `HTTP ${antwort.status}`, antwort.status, code);
    }
    const geprueft = schema.safeParse(daten);
    if (!geprueft.success) throw new ApiFehler(`Antwort von ${funktion} entspricht nicht dem erwarteten Schema`, antwort.status, 'SCHEMA');
    return geprueft.data;
  }
}
```

```ts
import type { Datenstand } from './schemas';

export type Standardjahre = { laufend: number; letztesMitIst: number | null; entwurf: number | null; alle: number[] };

/**
 * Standardjahre nach Spec 5.2: laufendes Haushaltsjahr (beschlossen) für Start und Explorer,
 * letztes Jahr mit Ist für „Plan und Wirklichkeit“, Entwurf nur auf ausdrückliche Wahl.
 */
export function standardjahre(stand: Datenstand, heute: Date): Standardjahre {
  const ausgaben = stand.jahre.filter((j) => j.konto === 'ausgaben');
  const alle = [...new Set(ausgaben.map((j) => j.jahr))].sort((a, b) => a - b);
  if (alle.length === 0) throw new Error('Datenstand enthält keine Jahre');
  const beschlossen = ausgaben.filter((j) => j.haushaltsstand !== 'Regierungsentwurf').map((j) => j.jahr);
  const kalender = heute.getUTCFullYear();
  const laufend = beschlossen.includes(kalender) ? kalender : Math.max(...(beschlossen.length > 0 ? beschlossen : alle));
  const mitIst = ausgaben.filter((j) => j.ist_verfuegbar).map((j) => j.jahr);
  return {
    laufend,
    letztesMitIst: mitIst.length > 0 ? Math.max(...mitIst) : null,
    entwurf: ausgaben.find((j) => j.haushaltsstand === 'Regierungsentwurf')?.jahr ?? null,
    alle,
  };
}

export function istVerfuegbar(stand: Datenstand, jahr: number, konto: 'ausgaben' | 'einnahmen'): boolean {
  return stand.jahre.some((j) => j.jahr === jahr && j.konto === konto && j.ist_verfuegbar);
}
```

```ts
export function leseParameter(sp: SuchParameter, jahre: Standardjahre): { param: ExplorerParameter; hinweise: string[] } {
  const hinweise: string[] = [];
  const jahrText = einzeln(sp, 'jahr');
  let jahr = jahre.laufend;
  if (jahrText !== undefined) {

  }
  const konto: Konto = einzeln(sp, 'konto') === 'einnahmen' ? 'einnahmen' : 'ausgaben';
  const sichtText = einzeln(sp, 'sicht');
  let sicht: Sicht = sichtText === 'aufgabe' || sichtText === 'art' ? sichtText : 'ressort';
  if (sicht === 'aufgabe' && konto === 'einnahmen') {
    sicht = 'ressort';
    hinweise.push('Die Sicht nach Aufgaben gibt es nur für Ausgaben.');
  }
  const pfad: Record<string, string> = {};
  let vorgaenger: string | null = null;
  for (const dim of EBENEN[sicht]) {
    if (dim === 'titel_key') break;
    const wert = einzeln(sp, URL_PARAM[dim]!);
    if (wert === undefined) break;
    if (!MUSTER[dim]!.test(wert)) {
      hinweise.push(`Die Auswahl „${wert}“ ist ungültig und wurde zurückgesetzt.`);
      break;
    }
    if (vorgaenger !== null && !wert.startsWith(vorgaenger)) {
      hinweise.push(`Die Auswahl „${wert}“ passt nicht zur übergeordneten Ebene und wurde zurückgesetzt.`);
      break;
    }
    pfad[dim] = wert;
    vorgaenger = wert;
  }
  return { param: { jahr, konto, sicht, pfad }, hinweise };
}

export function ebene(p: ExplorerParameter): Ebene {
  const dims = EBENEN[p.sicht];
  const offen = dims.findIndex((d) => !(d in p.pfad));
  const tiefe = offen === -1 ? dims.length - 1 : offen;
  const filter: Record<string, string> = {};
  for (const d of dims.slice(0, tiefe)) filter[d] = p.pfad[d]!;
  return { gruppierung: dims[tiefe]!, filter, tiefe, letzte: dims[tiefe] === 'titel_key' };
}

export function explorerHref(p: ExplorerParameter): string {
  const q = new URLSearchParams({ jahr: String(p.jahr), konto: p.konto, sicht: p.sicht });
  for (const d of EBENEN[p.sicht]) {
    const w = p.pfad[d];
    if (w === undefined) break;
    q.set(URL_PARAM[d]!, w);
  }
  return `/explorer?${q.toString()}`;
}

export function kindHref(p: ExplorerParameter, schluessel: string): string {
  const e = ebene(p);
  if (e.letzte) return `/titel/${p.jahr}/${schluessel}`;
  return explorerHref({ ...p, pfad: { ...e.filter, [e.gruppierung]: schluessel } });
}

export function bezeichnung(dim: string, schluessel: string, text: string | null | undefined): string {
  const s = dim === 'titel_key' && /^\d{9}$/.test(schluessel)
    ? `${schluessel.slice(0, 4)} ${schluessel.slice(4, 7)} ${schluessel.slice(7)}`
    : schluessel;
  return text ? `${s} ${text}` : s;
}

export function brotkrumen(p: ExplorerParameter, texte: Readonly<Record<string, string | null>>): { bezeichnung: string; href: string }[] {
  const krumen = [{ bezeichnung: 'Bund', href: explorerHref({ ...p, pfad: {} }) }];
  const bisher: Record<string, string> = {};
  for (const d of EBENEN[p.sicht]) {
    const w = p.pfad[d];
    if (w === undefined) break;
    bisher[d] = w;
    krumen.push({ bezeichnung: bezeichnung(d, w, texte[TEXTSPALTE[d]!] ?? null), href: explorerHref({ ...p, pfad: { ...bisher } }) });
  }
  return krumen;
}

export function trefferZiel(t: { typ: string; konto: Konto; schluessel: string }, jahr: number): string {
  const s = t.schluessel;
  const basis = { jahr, konto: t.konto };
  switch (t.typ) {
    case 'titel': return `/titel/${jahr}/${s}`;
    case 'einzelplan': return explorerHref({ ...basis, sicht: 'ressort', pfad: { einzelplan_nr: s } });
    case 'kapitel': return explorerHref({ ...basis, sicht: 'ressort', pfad: { einzelplan_nr: s.slice(0, 2), kapitel_nr: s } });
    case 'hauptfunktion': return explorerHref({ ...basis, sicht: 'aufgabe', pfad: { hauptfunktion: s } });
    case 'oberfunktion': return explorerHref({ ...basis, sicht: 'aufgabe', pfad: { hauptfunktion: s.slice(0, 1), oberfunktion: s } });
    case 'funktion': return explorerHref({ ...basis, sicht: 'aufgabe', pfad: { hauptfunktion: s.slice(0, 1), oberfunktion: s.slice(0, 2), fkt: s } });
    case 'hauptgruppe': return explorerHref({ ...basis, sicht: 'art', pfad: { hauptgruppe: s } });
    case 'obergruppe': return explorerHref({ ...basis, sicht: 'art', pfad: { hauptgruppe: s.slice(0, 1), obergruppe: s } });
    case 'gruppierung': return explorerHref({ ...basis, sicht: 'art', pfad: { hauptgruppe: s.slice(0, 1), obergruppe: s.slice(0, 2), gruppierung_nr: s } });
    default: return explorerHref({ ...basis, sicht: 'ressort', pfad: {} });
  }
}
```

```tsx
import { NOTATION } from '@/lib/ibcs/notation';
import { balken, kappe, position, type Masstab } from '@/lib/ibcs/skala';

const B = 100;
const H = 12;
const runde = (n: number) => Math.round(n * 1000) / 1000;

function Flaeche({ children }: { children: ReactNode }) {
  return (
    <svg viewBox={`0 0 ${B} ${H}`} preserveAspectRatio="none" className="block h-3 w-full overflow-visible" aria-hidden="true">
      {children}
    </svg>
  );
}

function Nulllinie({ masstab }: { masstab: Masstab }) {
  const x = runde(position(0, masstab, B));
  return <line x1={x} x2={x} y1={0} y2={H} className="ibcs-achse" vectorEffect="non-scaling-stroke" />;
}

/** Soll als Kontur (PL), Ist gefüllt davor (AC); beide beginnen an der Nulllinie. */
export function SzenarioBalken({ soll, ist = null, masstab, sollSzenario = 'soll' }: {
  soll: number | null; ist?: number | null; masstab: Masstab; sollSzenario?: 'soll' | 'entwurf';
}) {
  const s = soll === null ? null : balken(soll, masstab, B);
  const i = ist === null ? null : balken(ist, masstab, B);
  return (
    <Flaeche>
      {s && <rect x={runde(s.x)} y={0.75} width={runde(s.breite)} height={H - 1.5} className={NOTATION[sollSzenario].klasse} vectorEffect="non-scaling-stroke" />}
      {i && <rect x={runde(i.x)} y={3} width={runde(i.breite)} height={H - 6} className={NOTATION.ist.klasse} />}
      <Nulllinie masstab={masstab} />
    </Flaeche>
  );
}

export function AbweichungsBalken({ wert, masstab, farbe }: { wert: number | null; masstab: Masstab; farbe: Abweichungsfarbe }) {
  const a = wert === null ? null : balken(wert, masstab, B);
  return (
    <Flaeche>
      {a && <rect x={runde(a.x)} y={2} width={runde(a.breite)} height={H - 4} className={FARBKLASSE[farbe]} />}
      <Nulllinie masstab={masstab} />
    </Flaeche>
  );
}

/** Nadel für relative Abweichungen; Werte über ±100 % werden gekappt und mit hohlem Kopf markiert. */
export function Nadel({ wert, masstab, farbe }: { wert: number | null; masstab: Masstab; farbe: Abweichungsfarbe }) {
  if (wert === null) return <Flaeche><Nulllinie masstab={masstab} /></Flaeche>;
  const k = kappe(wert);
  const x0 = position(0, masstab, B);
  const x = position(k.wert, masstab, B);
  const kopf = 1.6;
  return (
    <Flaeche>
      <rect x={runde(Math.min(x0, x))} y={H / 2 - 0.6} width={runde(Math.abs(x - x0))} height={1.2} className={FARBKLASSE[farbe]} />
      <rect x={runde(x - kopf / 2)} y={H / 2 - 3} width={kopf} height={6} className={k.gekappt ? 'ibcs-gekappt' : FARBKLASSE[farbe]} vectorEffect="non-scaling-stroke" />
      <Nulllinie masstab={masstab} />
    </Flaeche>
  );
```

```tsx
import { Fussnoten } from './Fussnoten';
import { Titelblock } from './Titelblock';

export type StrukturZeile = {
  schluessel: string;
  bezeichnung: string;
  href?: string;
  soll: number | null;
  ist?: number | null;
  delta?: number | null;
  sollSzenario?: 'soll' | 'entwurf';
};

/** Sortierte horizontale Balken (IBCS Strukturanalyse), zugleich als zugängliche Tabelle. */
export function Strukturbalken({ id, titel, zeilen, masstab, einheit, deltaBeschriftung, hinweise = [], nominal = false, weitere }: {
  id: string;
  titel: Titel;
  zeilen: readonly StrukturZeile[];
  masstab?: Masstab;
  einheit?: Einheit;
  deltaBeschriftung?: string;
  hinweise?: readonly string[];
  nominal?: boolean;
  weitere?: { anzahl: number; href: string };
}) {
  const werte = zeilen.flatMap((z) => [z.soll, z.ist ?? null]);
  const m = masstab ?? berechneMasstab(werte);
  const e = einheit ?? einheitFuer(werte);
  const zeigeIst = zeilen.some((z) => z.ist !== undefined && z.ist !== null);
  const zeigeDelta = deltaBeschriftung !== undefined;
  const spalten = 3 + (zeigeIst ? 1 : 0) + (zeigeDelta ? 1 : 0);
  return (
    <figure aria-labelledby={`${id}-titel`} className="my-4">
      <figcaption><Titelblock id={`${id}-titel`} {...titel} /></figcaption>
      <table className="w-full border-collapse text-sm tabular-nums">
        <thead className="sr-only">
          <tr>
            <th scope="col">Bezeichnung</th>
            <th scope="col">Balken</th>
            {zeigeIst && <th scope="col">Ist</th>}
            <th scope="col">Soll</th>
            {zeigeDelta && <th scope="col">{deltaBeschriftung}</th>}
          </tr>
        </thead>
        <tbody>
          {zeilen.length === 0 && <tr><td colSpan={spalten} className="py-2 text-[var(--hb-gedaempft)]">Keine Daten für diese Auswahl.</td></tr>}
          {zeilen.map((z) => (
            <tr key={z.schluessel} className="align-middle">
              <th scope="row" className="w-2/5 py-0.5 pr-2 text-left font-normal">
                {z.href ? <a href={z.href}>{z.bezeichnung}</a> : z.bezeichnung}
              </th>
              <td className="w-2/5"><SzenarioBalken soll={z.soll} ist={z.ist ?? null} masstab={m} sollSzenario={z.sollSzenario} /></td>
              {zeigeIst && <td className="pl-2 text-right">{betrag(z.ist, e)}</td>}
              <td className="pl-2 text-right">{betrag(z.soll, e)}</td>
              {zeigeDelta && <td className="pl-2 text-right text-[var(--hb-gedaempft)]">{betrag(z.delta ?? null, e, { vorzeichen: true })}</td>}
            </tr>
          ))}
          {weitere && weitere.anzahl > 0 && (
            <tr><td colSpan={spalten} className="pt-1 text-sm"><a href={weitere.href}>… {weitere.anzahl} weitere</a></td></tr>
          )}
        </tbody>
      </table>
      <Fussnoten hinweise={hinweise} nominal={nominal} />
    </figure>
  );
}
```

```tsx
import { abweichungsfarbe, FARBKLASSE, type Wirkung } from '@/lib/ibcs/farbe';
import { betrag, einheitFuer, type Einheit } from '@/lib/ibcs/format';
import { NOTATION } from '@/lib/ibcs/notation';
import { masstab, position } from '@/lib/ibcs/skala';
import type { Titel } from '@/lib/ibcs/titel';
import { Fussnoten } from './Fussnoten';
import { Titelblock } from './Titelblock';

export type Zeitpunkt = {
  jahr: number;
  soll: number | null;
  ist: number | null;
  sollSzenario: 'soll' | 'entwurf';
  haushaltsplan?: number | null;
  abweichung?: number | null;
  markierung?: string;
};

const SPALTE = 44;
const OBEN = 18;
const HOEHE = 120;
const UNTEN = 16;
const ABW = 36;
const runde = (n: number) => Math.round(n * 100) / 100;

/** Zeitreihe als Säulen (Zeit horizontal): Soll als Kontur, Ist gefüllt, Entwurf gekennzeichnet, darunter ΔPL je Jahr. */
export function ZeitreiheSaeulen({ id, titel, punkte, wirkung = 'neutral', hinweise = [], einheit }: {
  id: string; titel: Titel; punkte: readonly Zeitpunkt[]; wirkung?: Wirkung; hinweise?: readonly string[]; einheit?: Einheit;
}) {
  const werte = punkte.flatMap((p) => [p.soll, p.ist, p.haushaltsplan ?? null]);
  const m = masstab(werte);
  const e = einheit ?? einheitFuer(werte);
  const abw = punkte.map((p) => p.abweichung ?? null);
  const zeigeAbw = abw.some((w) => w !== null);
  const ma = masstab(abw);
  const breite = Math.max(punkte.length, 1) * SPALTE;
  const hoehe = OBEN + HOEHE + UNTEN + (zeigeAbw ? ABW : 0);
  const y = (w: number) => OBEN + HOEHE - position(w, m, HOEHE);
  const y0 = y(0);
  const basisAbw = OBEN + HOEHE + UNTEN;
  const ya = (w: number) => basisAbw + ABW - 4 - position(w, ma, ABW - 8);
  const ya0 = ya(0);
  return (
    <figure className="my-4">
      <figcaption><Titelblock id={`${id}-titel`} {...titel} /></figcaption>
      <svg viewBox={`0 0 ${breite} ${hoehe}`} className="h-auto w-full" role="img" aria-labelledby={`${id}-titel`}>
        {punkte.map((p, i) => {
          const x = i * SPALTE + 8;
          const w = SPALTE - 16;
          const anzeige = p.ist ?? p.soll;
          return (
            <g key={p.jahr}>
              {p.markierung && (
                <>
                  <line x1={i * SPALTE} x2={i * SPALTE} y1={4} y2={OBEN + HOEHE} className="ibcs-trenner" />
                  <text x={i * SPALTE + 2} y={10} className="ibcs-text-gedaempft">{p.markierung}</text>
                </>
              )}
              {p.soll !== null && (
                <rect x={x} y={runde(Math.min(y(p.soll), y0))} width={w} height={runde(Math.abs(y(p.soll) - y0))}
                  className={NOTATION[p.sollSzenario].klasse} />
              )}
              {p.ist !== null && (
                <rect x={x + 4} y={runde(Math.min(y(p.ist), y0))} width={w - 8} height={runde(Math.abs(y(p.ist) - y0))} className="ibcs-ist" />
              )}
              {p.haushaltsplan !== undefined && p.haushaltsplan !== null && (
                <rect x={x - 2} y={runde(Math.min(y(p.haushaltsplan), y0))} width={w + 4} height={runde(Math.abs(y(p.haushaltsplan) - y0))}
                  className={NOTATION.haushaltsplan.klasse} />
              )}
              {anzeige !== null && (
                <text x={x + w / 2} y={runde(anzeige >= 0 ? Math.min(y(anzeige), y0) - 3 : Math.max(y(anzeige), y0) + 9)} textAnchor="middle" className="ibcs-text">
                  {betrag(anzeige, e)}
                </text>
              )}
              <text x={x + w / 2} y={OBEN + HOEHE + 11} textAnchor="middle" className="ibcs-text">
                {p.sollSzenario === 'entwurf' ? `${p.jahr} E` : p.jahr}
              </text>
              {zeigeAbw && p.abweichung !== undefined && p.abweichung !== null && (
                <>
                  <rect x={x + 4} y={runde(Math.min(ya(p.abweichung), ya0))} width={w - 8} height={runde(Math.abs(ya(p.abweichung) - ya0))}
                    className={FARBKLASSE[abweichungsfarbe(p.abweichung, wirkung, 'plan')]} />
                  <text x={x + w / 2} y={basisAbw + 6} textAnchor="middle" className="ibcs-text-gedaempft">{betrag(p.abweichung, e, { vorzeichen: true })}</text>
                </>
              )}
            </g>
          );
        })}
        <line x1={0} x2={breite} y1={runde(y0)} y2={runde(y0)} className="ibcs-achse" />
        {zeigeAbw && <line x1={0} x2={breite} y1={runde(ya0)} y2={runde(ya0)} className="ibcs-achse" />}
      </svg>
      <table className="sr-only">
        <caption>{titel.wer}: Werte je Jahr in {e.kurz}</caption>
        <thead><tr><th scope="col">Jahr</th><th scope="col">Soll</th><th scope="col">Ist</th><th scope="col">Abweichung</th></tr></thead>
        <tbody>
          {punkte.map((p) => (
            <tr key={p.jahr}>
              <th scope="row">{p.sollSzenario === 'entwurf' ? `${p.jahr} (Entwurf)` : p.jahr}</th>
              <td>{betrag(p.soll, e)}</td>
              <td>{betrag(p.ist, e)}</td>
              <td>{betrag(p.abweichung ?? null, e, { vorzeichen: true })}</td>
            </tr>
          ))}
        </tbody>
      </table>
      <Fussnoten hinweise={hinweise} nominal />
    </figure>
  );
}
```

```tsx
import { abweichungsfarbe, type Wirkung } from '@/lib/ibcs/farbe';
import { betrag, einheitFuer, prozent, type Einheit } from '@/lib/ibcs/format';
import { masstab } from '@/lib/ibcs/skala';
import type { Titel } from '@/lib/ibcs/titel';
import { AbweichungsBalken, SzenarioBalken } from './Balken';
import { Fussnoten } from './Fussnoten';

export type TabellenZeile = {
  schluessel: string;
  bezeichnung: string;
  href?: string;
  soll: number | null;
  ist?: number | null;
  abweichung?: number | null;
  abweichungRel?: number | null;
  deltaVj?: number | null;
  anteil?: number | null;
  wirkung?: Wirkung;
  sollSzenario?: 'soll' | 'entwurf';
};

const NEBEN = 'hidden sm:table-cell';
const ZAHL = 'px-2 py-1 text-right whitespace-nowrap';

/** IBCS-Tabelle mit eingebetteten Szenario- und Abweichungsbalken (Spec 5.5). */
export function IbcsTabelle({ id, titel, modus, zeilen, summe, einheit, hinweise = [], nominal = false }: {
  id: string; titel: Titel; modus: 'plan_ist' | 'soll'; zeilen: readonly TabellenZeile[]; summe?: TabellenZeile;
  einheit?: Einheit; hinweise?: readonly string[]; nominal?: boolean;
}) {
  const e = einheit ?? einheitFuer(zeilen.flatMap((z) => [z.soll, z.ist ?? null]));
  const mS = masstab(zeilen.flatMap((z) => [z.soll, z.ist ?? null]));
  const mA = masstab(zeilen.map((z) => z.abweichung ?? null));
  const planIst = modus === 'plan_ist';
  const spalten = planIst ? 7 : 5;

  const zellen = (z: TabellenZeile, summenzeile: boolean) => (
    <>

        {z.href && !summenzeile ? <a href={z.href}>{z.bezeichnung}</a> : z.bezeichnung}
      </th>
      <td className={ZAHL}>{betrag(z.soll, e)}</td>
      {planIst && <td className={ZAHL}>{betrag(z.ist ?? null, e)}</td>}
      <td className="w-1/5 min-w-24 px-2">
        {!summenzeile && <SzenarioBalken soll={z.soll} ist={planIst ? z.ist ?? null : null} masstab={mS} sollSzenario={z.sollSzenario} />}
      </td>

        <>
          <td className={`${NEBEN} w-1/6 min-w-20 px-2`}>
            {!summenzeile && <AbweichungsBalken wert={z.abweichung ?? null} masstab={mA} farbe={abweichungsfarbe(z.abweichung, z.wirkung, 'plan')} />}
          </td>
          <td className={ZAHL}>{betrag(z.abweichung ?? null, e, { vorzeichen: true })}</td>
          <td className={`${NEBEN} ${ZAHL}`}>{prozent(z.abweichungRel ?? null, { vorzeichen: true })}</td>
        </>
      ) : (
        <>
          <td className={`${ZAHL} text-[var(--hb-gedaempft)]`}>{betrag(z.deltaVj ?? null, e, { vorzeichen: true })}</td>

                  <th scope="col" className={`${NEBEN} ${ZAHL}`}>ΔPL %</th>
                </>
              ) : (
                <>
                  <th scope="col" className={ZAHL}>Δ Soll Vorjahr</th>
                  <th scope="col" className={`${NEBEN} ${ZAHL}`}>Anteil</th>
```

```ts
import { timingSafeEqual } from 'node:crypto';
import { revalidateTag } from 'next/cache';
import { CACHE_TAG } from '@/lib/daten/rpc';

function gleich(a: string, b: string): boolean {
  const x = Buffer.from(a);
  const y = Buffer.from(b);
  return x.length === y.length && timingSafeEqual(x, y);
}

/** Vom Workflow ingest nach jeder Veröffentlichung aufgerufen; verwirft alle gecachten API-Antworten. */
export async function POST(request: Request): Promise<Response> {
  const erwartet = process.env.REVALIDATE_TOKEN;
  const kopf = request.headers.get('authorization') ?? '';
  const token = kopf.startsWith('Bearer ') ? kopf.slice(7) : '';
  if (!erwartet || !token || !gleich(token, erwartet)) return Response.json({ ok: false }, { status: 401 });
  revalidateTag(CACHE_TAG, { expire: 0 });
  return Response.json({ ok: true });
}
```

```ts
import { ladeDatenstand, suche } from '@/lib/daten/abfragen';
import { standardjahre } from '@/lib/daten/jahre';
import { TYP_BEZEICHNUNG, trefferZiel } from '@/lib/explorer';
import { heute } from '@/lib/zeit';

export async function GET(request: Request): Promise<Response> {
  const q = new URL(request.url).searchParams.get('q')?.trim() ?? '';
  if (q.length < 2 || q.length > 200) return Response.json({ treffer: [] });
  try {
    const stand = await ladeDatenstand();
    const jahre = standardjahre(stand, heute());
    const s = await suche(q, { jahr: jahre.laufend, limit: 8, version: stand.version });
    return Response.json({
      treffer: s.treffer.map((t) => ({
        typ: t.typ,
        typBezeichnung: TYP_BEZEICHNUNG[t.typ] ?? t.typ,
        bezeichnung: t.bezeichnung ?? t.schluessel,
        schluessel: t.schluessel,
        treffer: t.treffer,
        href: trefferZiel(t, s.jahr),
      })),
    });
  } catch {
    return Response.json({ treffer: [], fehler: 'Die Suche ist gerade nicht verfügbar.' }, { status: 503 });
  }
}
```

```tsx
'use client';

import { useRouter } from 'next/navigation';
import { useEffect, useId, useRef, useState, type KeyboardEvent } from 'react';

type Vorschlag = { typ: string; typBezeichnung: string; bezeichnung: string; schluessel: string; treffer: string; href: string };

/** Suchfeld mit Vorschlägen (Combobox nach WAI-ARIA); ohne JavaScript sendet das Formular an /suche. */
export function Suche() {
  const router = useRouter();
  const listeId = useId();
  const [q, setQ] = useState('');
  const [vorschlaege, setVorschlaege] = useState<Vorschlag[]>([]);
  const [aktiv, setAktiv] = useState(-1);
  const [offen, setOffen] = useState(false);
  const abbruch = useRef<AbortController | null>(null);

  useEffect(() => {
    const begriff = q.trim();
    if (begriff.length < 2) {
      setVorschlaege([]);
      return;
    }
    const zeit = setTimeout(async () => {
      abbruch.current?.abort();
      const ctrl = new AbortController();
      abbruch.current = ctrl;
      try {
        const r = await fetch(`/api/suche?q=${encodeURIComponent(begriff)}`, { signal: ctrl.signal });
        const daten = (await r.json()) as { treffer: Vorschlag[] };
        setVorschlaege(daten.treffer);
        setAktiv(-1);
        setOffen(true);
      } catch {
        // abgebrochen oder offline: Vorschläge bleiben unverändert
      }
    }, 250);
    return () => clearTimeout(zeit);
  }, [q]);

  function gehe(v: Vorschlag) {
    router.push(v.href);
    setOffen(false);
  }

  function taste(e: KeyboardEvent<HTMLInputElement>) {
    if (e.key === 'ArrowDown') { e.preventDefault(); setOffen(true); setAktiv((a) => Math.min(a + 1, vorschlaege.length - 1)); }
    else if (e.key === 'ArrowUp') { e.preventDefault(); setAktiv((a) => Math.max(a - 1, -1)); }
    else if (e.key === 'Escape') setOffen(false);
    else if (e.key === 'Enter') {
      const v = aktiv >= 0 ? vorschlaege[aktiv] : undefined;
      if (v) { e.preventDefault(); gehe(v); }
    }
  }

  return (
    <form action="/suche" method="get" role="search" className="relative w-full max-w-sm">
      <label htmlFor={`${listeId}-feld`} className="sr-only">Suche im Bundeshaushalt</label>
      <input id={`${listeId}-feld`} name="q" value={q} onChange={(e) => setQ(e.target.value)} onKeyDown={taste}
        onBlur={() => setTimeout(() => setOffen(false), 150)} onFocus={() => { if (vorschlaege.length > 0) setOffen(true); }}
        role="combobox" aria-expanded={offen && vorschlaege.length > 0} aria-controls={listeId} aria-autocomplete="list"
        aria-activedescendant={aktiv >= 0 ? `${listeId}-${aktiv}` : undefined} maxLength={200} autoComplete="off"
        placeholder="Suchen, z. B. „Bundeswehr“, „BAföG“"
        className="w-full rounded border border-[var(--hb-linie)] bg-[var(--hb-bg)] px-3 py-1.5 text-sm" />
      {offen && vorschlaege.length > 0 && (
        <ul id={listeId} role="listbox" aria-label="Vorschläge" className="absolute z-10 mt-1 w-full rounded border border-[var(--hb-linie)] bg-[var(--hb-bg)] py-1 text-sm shadow">
          {vorschlaege.map((v, i) => (
            <li key={`${v.typ}-${v.schluessel}`} id={`${listeId}-${i}`} role="option" aria-selected={i === aktiv}
              className={`cursor-pointer px-3 py-1 ${i === aktiv ? 'bg-[var(--hb-flaeche)]' : ''}`}
              onMouseDown={(e) => { e.preventDefault(); gehe(v); }}>

            </li>
          ))}
```

```ts
export function zahl(z: Zeile | undefined, name: string): number | null {
  const w = z?.[name];
  return typeof w === 'number' ? w : null;
}

export function text(z: Zeile | undefined, name: string): string | null {
  const w = z?.[name];
  if (typeof w === 'string') return w;
  if (typeof w === 'number') return String(w);
  return null;
```

```ts
import { istVerfuegbar, type Standardjahre } from './daten/jahre';
import type { Datenstand, Zeile } from './daten/schemas';
import { einzeln, type SuchParameter } from './seite';

export type PlanIstEbene = 'einzelplan' | 'kapitel' | 'titel';
export const EBENE_DIM: Record<PlanIstEbene, string> = { einzelplan: 'einzelplan_nr', kapitel: 'kapitel_nr', titel: 'titel_key' };

/** Auswahl der größten Abweichungen nach Betrag aus den Abfragen „absteigend“ und „aufsteigend“ (reine Darstellung). */
export function groessteAbweichungen(zeilen: readonly Zeile[], dim: string, kennzahl: 'abweichung' | 'abweichung_rel', n: number): Zeile[] {
  const gesehen = new Set<string>();
  const eindeutig: Zeile[] = [];
  for (const z of zeilen) {
    const k = String(z[dim]);
    const w = z[kennzahl];
    if (gesehen.has(k) || typeof w !== 'number') continue;
    gesehen.add(k);
    eindeutig.push(z);
  }
  return eindeutig.sort((a, b) => Math.abs(b[kennzahl] as number) - Math.abs(a[kennzahl] as number)).slice(0, n);
}

export function lesePlanIstParameter(sp: SuchParameter, stand: Datenstand, jahre: Standardjahre): {
  jahr: number; konto: 'ausgaben' | 'einnahmen'; ebene: PlanIstEbene; sortierung: 'abweichung' | 'abweichung_rel'; hinweise: string[];
} {
  const hinweise: string[] = [];
  const konto = einzeln(sp, 'konto') === 'einnahmen' ? 'einnahmen' as const : 'ausgaben' as const;
  const standard = jahre.letztesMitIst ?? jahre.laufend;
  let jahr = standard;
  const jahrText = einzeln(sp, 'jahr');
  if (jahrText !== undefined) {
    const j = Number(jahrText);
    if (Number.isInteger(j) && istVerfuegbar(stand, j, konto)) jahr = j;
    else hinweise.push(`Für ${jahrText} liegt noch kein Ist vor. Gezeigt wird ${standard}, das letzte abgeschlossene Jahr.`);
  }
  const e = einzeln(sp, 'ebene');
  const ebene: PlanIstEbene = e === 'kapitel' || e === 'titel' ? e : 'einzelplan';
  const sortierung = einzeln(sp, 'sortierung') === 'relativ' ? 'abweichung_rel' as const : 'abweichung' as const;
  return { jahr, konto, ebene, sortierung, hinweise };
}
```

```ts
import type { Zeitpunkt } from '@/components/ibcs/ZeitreiheSaeulen';
import type { TitelDetail } from './daten/schemas';
import { sollSzenario } from './ibcs/notation';

export function zeitpunkte(d: TitelDetail, mitHaushaltsplan: boolean): Zeitpunkt[] {
  return d.zeitreihe.map((z, i) => {
    const vorher = i > 0 ? d.zeitreihe[i - 1] : undefined;
    return {
      jahr: z.jahr,
      soll: z.soll_eur,
      ist: z.ist_verfuegbar ? z.ist_eur : null,
      sollSzenario: sollSzenario(z.haushaltsstand),
      haushaltsplan: mitHaushaltsplan ? z.soll_xml_eur : undefined,
      abweichung: z.abweichung_eur,
      markierung: vorher && vorher.titel_key !== z.titel_key ? `ab ${z.jahr}: Kapitel ${z.kapitel_nr ?? z.titel_key.slice(0, 4)}` : undefined,
    };
  });
}

export function flexibilisiertText(w: boolean | null): string {
  if (w === null) return 'nicht anwendbar';
  return w ? 'ja' : 'nein';
}

export function luecke(d: TitelDetail, erstesJahr: number): string | null {
  const erstes = d.zeitreihe[0]?.jahr;
  if (erstes === undefined || erstes <= erstesJahr) return null;
  return `Für Jahre vor ${erstes} gibt es keine eindeutige Zuordnung, oder der Titel bestand noch nicht.`;
}
```

```ts
/** Pflichtangaben stehen nur in Umgebungsvariablen (Vercel), nie im Repository. */
export function impressum(env: Record<string, string | undefined> = process.env): { name: string; anschrift: string[]; kontakt: string } | null {
  const name = env.HB_IMPRESSUM_NAME?.trim();
  const anschrift = env.HB_IMPRESSUM_ANSCHRIFT?.split('|').map((z) => z.trim()).filter(Boolean);
  const kontakt = env.HB_IMPRESSUM_KONTAKT?.trim();
  if (!name || !anschrift || anschrift.length === 0 || !kontakt) return null;
  return { name, anschrift, kontakt };
}
```

```js
// Liefert aufgezeichnete Antworten der Data API für Ende-zu-Ende-Tests; mit HB_AUFNAHME_QUELLE wird aufgezeichnet.
import { createHash } from 'node:crypto';
import { mkdir, readFile, writeFile } from 'node:fs/promises';
import { createServer } from 'node:http';

const VERZEICHNIS = new URL('./aufnahmen/', import.meta.url);
const PORT = Number(process.env.FIXTURE_PORT ?? 4010);
const QUELLE = process.env.HB_AUFNAHME_QUELLE?.replace(/\/+$/, '');
const KEY = process.env.HB_AUFNAHME_KEY;
const name = (pfad) => `${createHash('sha256').update(pfad).digest('hex').slice(0, 24)}.json`;

createServer(async (req, res) => {
  const pfad = req.url ?? '/';
  if (pfad === '/health') return res.writeHead(200).end('ok');
  const datei = new URL(name(pfad), VERZEICHNIS);
  try {
    if (QUELLE) {
      const antwort = await fetch(QUELLE + pfad, { headers: { apikey: KEY ?? '', 'Accept-Profile': 'api', Accept: 'application/json' } });
      const text = await antwort.text();
      await mkdir(VERZEICHNIS, { recursive: true });
      await writeFile(datei, `${JSON.stringify({ pfad, status: antwort.status, text }, null, 1)}\n`);
      return res.writeHead(antwort.status, { 'content-type': 'application/json' }).end(text);
    }
    const aufnahme = JSON.parse(await readFile(datei, 'utf8'));
    return res.writeHead(aufnahme.status, { 'content-type': 'application/json' }).end(aufnahme.text);
  } catch {
    return res.writeHead(500, { 'content-type': 'application/json' })
      .end(JSON.stringify({ code: 'AUFNAHME', message: `Keine Aufnahme für ${pfad}. Neu aufnehmen mit HB_AUFNAHME_QUELLE.` }));
  }
}).listen(PORT, '127.0.0.1');
```
